# Данные и метрики

`data/train.json`: 64 вручную составленных синтетических текста, по 16 на тему.
`data/test.json`: 28 отдельных текстов, в том числе менее прямые формулировки. Текстовые дубли между train и test проверяются программно.
`data/reviews.csv`: 40 демонстрационных отзывов (32 с оценкой ≤3 и 8 положительных). Часть демонстрационных отзывов взята из train: метрики считаются только на отдельном test, не на этом CSV.

CSV содержит `review_id,text,rating,date`. Кодировка UTF-8 (BOM допустим), разделитель запятая, текст с запятой берите в двойные кавычки. ID уникальные, rating — целое 1..5, date — ISO YYYY-MM-DD. Лимиты: 5000 строк и 1.5 МБ текста.

Основные метрики: macro-F1 до отказов, confusion matrix, доля принятых предсказаний (coverage), accuracy только принятых (accepted_accuracy). Уверенность модели — не калиброванная вероятность правильности.

Приоритизация: `100 * count / total_unique_reviews * severity / 5`. Severity зафиксирована в core.py; score не является RICE и не учитывает усилия разработки. Для неподтверждённой темы используется отдельная очередь ручной проверки. Исправление хранится с хешем исходного текста, поэтому новый текст с прежним ID не получает чужую метку.
