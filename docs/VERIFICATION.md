# Проверки выполненной версии

Среда: Python 3.12.14, Linux. Дата подготовки: 29.10.2026.

- 7 автоматических тестов unittest прошли.
- 12 HTTP-проверок прошли на реально запущенном локальном сервере с временной SQLite: статические файлы, health, маршруты, ошибки ввода и основные пользовательские операции.
- Python-файлы проверены через AST; JavaScript — Node.js --check.
- Команда `python app.py demo` выполнена; её результаты включены в reports/example.
- ZIP проверен на целостность при упаковке.

## Что не проверялось

- Графическое отображение и клики в настоящем браузере: браузерный движок в среде отсутствует. Проверка JS-синтаксиса и HTTP не заменяет визуальную проверку.
- Windows BAT и установка в чистой Windows; основной запуск тестировался в Linux.
- Реальные платные LLM API и наличие доступа к выбранной пользователем модели.
- GitHub Actions в удалённом репозитории (конфигурация добавлена, удалённый запуск не выполнялся).
- Реальные клиенты, бизнес-эффект и пользовательская проверка на добровольцах.



Для повторения основных проверок: `python -m unittest discover -s tests -v`, затем `python app.py demo`.
