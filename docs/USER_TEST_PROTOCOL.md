# Протокол пользовательской проверки — FeedbackRadar

Это подготовленный протокол, а не результаты уже проведённого исследования.

1. Пригласите 3–5 добровольцев из целевой аудитории и объясните задачу.
2. Дайте пройти сценарий из DEMO.md без подсказок; попросите проговаривать затруднения.
3. Зафиксируйте выполнение задачи, время, ошибки и понятность результата по шкале 1–5.
4. Не собирайте пароли, платёжные данные и реальные обращения с персональными данными.
5. Сгруппируйте наблюдения, выберите 2–3 изменения и повторите проверку.

| Участник (псевдоним) | Задача | Выполнено | Время, с | Затруднение | Понятность 1–5 | Изменение |
|---|---|---|---:|---|---:|---|
| — | — | — | — | — | — | — |

Числа в резюме добавляйте после заполнения таблицы реальными наблюдениями. Время от API не заменяет время пользовательского сценария.
